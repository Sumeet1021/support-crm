# SupportDesk CRM

A full-stack customer support ticket management system built with FastAPI and React.

## Features

- Create support tickets
- Search tickets
- Filter by status
- Update ticket status
- View ticket details

## Tech Stack

Backend:
- FastAPI
- SQLite
- SQLAlchemy

Frontend:
- React
- Vite
- Axios

Deployment:
- Render

## Live Demo

Frontend:
https://supportdesk-frontend-mti0.onrender.com

Backend:

## Run Locally

### Backend

pip install -r requirements.txt
uvicorn main:app --reload

### Frontend

npm install
npm run dev
